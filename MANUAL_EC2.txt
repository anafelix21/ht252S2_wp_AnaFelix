INBOUND SECURITY GROUP RULES:

Regla 1 - SSH (Acceso remoto):
┌──────────────┬──────────┬───────────┬──────────────┐
│ Type         │ Protocol │ Port Range│ Source type  │
├──────────────┼──────────┼───────────┼──────────────┤

PASO 11: CREAR IP ELÁSTICA
---------------------------

EXPLICACIÓN:
La IP pública asignada automáticamente cambia si reinicias la instancia.
Una IP Elástica es permanente y no cambia.

1. En EC2 Dashboard, panel izquierdo: Network & Security > Elastic IPs

2. Click "Allocate Elastic IP address"

3. Configurar:
   Network Border Group:
   ┌─────────────────────────────────┐
   │ us-east-1 (o tu región)         │
   └─────────────────────────────────┘

   Public IPv4 address pool:
   ○ Amazon's pool of IPv4 addresses ✓

4. Tags (opcional):
   Key: Name, Value: hackaton-eip

5. Click "Allocate"

6. Ver mensaje de éxito:
   ✅ Successfully allocated Elastic IP address
   
   New address: 98.87.67.95 (ejemplo)

⚠️ IMPORTANTE: 
- IP Elástica es GRATIS si está asociada a instancia en ejecución
- Cobra $0.005/hora (~$3.60/mes) si está SIN USAR
- SIEMPRE asociarla a una instancia o liberarla


PASO 12: ASOCIAR IP ELÁSTICA A INSTANCIA
-----------------------------------------

1. Seleccionar la IP Elástica recién creada (98.87.67.95)

2. Actions > Associate Elastic IP address

3. Configurar:
   Resource type:
   ○ Instance ✓
   ○ Network interface

   Instance:
   ┌─────────────────────────────────┐
   │ i-xxx hackaton-flask-app        │
   └─────────────────────────────────┘

   Private IP address:
   ┌─────────────────────────────────┐
   │ 172.31.x.x (se llena automático)│
   └─────────────────────────────────┘

   ☑ Allow this Elastic IP address to be reassociated

4. Click "Associate"

5. Ver mensaje de éxito:
   ✅ Successfully associated Elastic IP address

6. Volver a EC2 > Instances

7. Verificar que "Public IPv4 address" ahora es: 98.87.67.95

GUARDAR ESTA IP:
┌─────────────────────────────────┐
│ IP Elástica: 98.87.67.95        │
└─────────────────────────────────┘

Esta es tu IP PERMANENTE para acceder a la aplicación.

PASO 14: CONECTAR VÍA SSH
--------------------------

Desde PowerShell:

```powershell
ssh -i "C:\Users\anacr\Downloads\ani.pem" ubuntu@98.87.67.95
```

EXPLICACIÓN:
- ssh: Comando para conexión segura
- -i: Especifica archivo de clave privada
- ubuntu: Usuario por defecto en Ubuntu AMI
- 98.87.67.95: Tu IP Elástica

Primera vez que te conectas:

Verás mensaje:
```
The authenticity of host '98.87.67.95 (98.87.67.95)' can't be established.
ECDSA key fingerprint is SHA256:abc123...
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

Escribir: yes

Ver mensaje de bienvenida:
```
Welcome to Ubuntu 22.04.3 LTS (GNU/Linux 6.2.0-1009-aws x86_64)

 * Documentation:  https://help.ubuntu.com
 * Management:     https://landscape.canonical.com
 * Support:        https://ubuntu.com/advantage

ubuntu@ip-172-31-x-x:~$
```

✅ ¡Conectado exitosamente!


SOLUCIÓN DE PROBLEMAS DE CONEXIÓN:

ERROR: "Permission denied (publickey)"
SOLUCIÓN:
- Verificar que usas usuario "ubuntu" (no "root" o "admin")
- Verificar ruta correcta del archivo .pem
- Verificar que descargaste la clave correcta

ERROR: "Connection timed out"
SOLUCIÓN:
- Verificar Security Group permite puerto 22 desde tu IP
- Verificar que usas la IP Elástica correcta
- Verificar que la instancia está en estado "Running"

ERROR: "Host key verification failed"
SOLUCIÓN:
- Eliminar entrada antigua: ssh-keygen -R 98.87.67.95
- Intentar conectar nuevamente

PASO 32: PROBAR CONEXIÓN A RDS
-------------------------------

```bash
# Crear script de prueba
nano test_rds_connection.py
```

Copiar este código:
```python
#!/usr/bin/env python3
from flask import Flask
from flask_mysqldb import MySQL
import MySQLdb.cursors

app = Flask(__name__)

# Configuración de RDS (usa tus credenciales reales)
app.config['MYSQL_HOST'] = 'hackaton-mysql-db.c9akciq32.us-east-1.rds.amazonaws.com'
app.config['MYSQL_USER'] = 'admin'
app.config['MYSQL_PASSWORD'] = 'TuPasswordSeguro123!'
app.config['MYSQL_DB'] = 'hackaton'

mysql = MySQL(app)

with app.app_context():
    try:
        cursor = mysql.connection.cursor()
        cursor.execute('SELECT VERSION()')
        version = cursor.fetchone()
        print(f'✅ Conexión exitosa a RDS MySQL')
        print(f'📊 MySQL version: {version[0]}')
        
        cursor.execute('SELECT COUNT(*) FROM equipos')
        count = cursor.fetchone()
        print(f'📦 Total de equipos en base de datos: {count[0]}')
        
        cursor.close()
    except Exception as e:
        print(f'❌ Error de conexión: {e}')
```

Guardar (Ctrl+O, Enter, Ctrl+X)

Ejecutar prueba:
```bash
python3 test_rds_connection.py
```


✅ Si ves este mensaje, la conexión a RDS funciona!

❌ Si hay error, verificar:
1. Endpoint de RDS correcto en app.py
2. Credenciales correctas
3. Security Group de RDS permite conexión desde EC2
4. Base de datos 'hackaton' existe en RDS
5. Tabla 'equipos' existe en la base de datos
