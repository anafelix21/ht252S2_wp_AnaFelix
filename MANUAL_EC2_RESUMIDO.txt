PASO 12: CONFIGURAR GUNICORN
-----------------------------

```bash
# Crear archivo de servicio
sudo nano /etc/systemd/system/hackaton-flask.service
```

Contenido:
```ini
[Unit]
Description=Hackaton Flask Application
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/ht252S2_wp_AnaFelix
Environment="PATH=/home/ubuntu/ht252S2_wp_AnaFelix/venv/bin"
ExecStart=/home/ubuntu/ht252S2_wp_AnaFelix/venv/bin/gunicorn --workers 3 --bind 0.0.0.0:5000 app:app

[Install]
WantedBy=multi-user.target
```

Guardar: Ctrl+O, Enter, Ctrl+X


PASO 13: INICIAR SERVICIO
--------------------------

```bash
# Recargar systemd
sudo systemctl daemon-reload

# Iniciar servicio
sudo systemctl start hackaton-flask

# Habilitar en arranque
sudo systemctl enable hackaton-flask

# Verificar estado
sudo systemctl status hackaton-flask
```


PASO 14: CONFIGURAR FIREWALL
-----------------------------

```bash

sudo ufw allow 80
```
